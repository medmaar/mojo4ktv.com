IPTV Codes 2026 — Xtream Codes, M3U URLs & Playlists Explained

What Are IPTV Codes?

"IPTV codes" refers to the authentication credentials used to log into an IPTV service. There are two formats: Xtream Codes API (a server URL, username, and password) and M3U playlist URLs (a single link containing all channel streams). Every Mojo 4K subscription provides both formats.

Xtream Codes Format

Your Xtream Codes credentials look like this:
Server: http://server.mojo4ktv.com:PORT
Username: yourname
Password: yourpass123
Enter these in TiviMate under Settings → Playlists → Add → Xtream Codes API. In IPTV Smarters Pro, tap "Login via Xtream Codes API" and enter all three fields.

M3U URL Format

Your M3U URL looks like this:
http://server.mojo4ktv.com:PORT/get.php?username=USER&password=PASS&type=m3u_plus
Paste this URL into TiviMate (M3U Playlist option), Kodi's IPTV Simple Client, VLC (Media → Open Network Stream), or any M3U-compatible player.

Which Format Should I Use?

Use Xtream Codes for TiviMate and IPTV Smarters Pro — it enables full EPG, VOD browsing, series organization, and catch-up TV. Use M3U URL for Kodi, VLC, Perfect Player, and apps that don't support Xtream Codes. Both formats access the same 50,000+ channels and are included with every Mojo 4K subscription.

M3U Playlist URL

# M3U_plus format URL

# Standard M3U
http://server.mojo4ktv.com:8080/get.php?username=USER&password=PASS&type=m3u

Used by: VLC, Kodi, Smart IPTV on Samsung/LG, MX Player. Works anywhere M3U is supported. Use m3u_plus for channel logos and categories.

Where to Enter Your IPTV Codes — App by App

TiviMate

Settings → Playlists → Add Playlist → Xtream Codes API. Enter Server URL (without http://), Username, Password. Tap Add. EPG and all channels load automatically.

IPTV Smarters Pro

Add User → Xtream Codes API. Enter Server URL, Username, Password. Tap Add User. Works on Android, iOS, Windows, Mac, Apple TV.

VLC (M3U)

Media → Open Network Stream → paste your M3U_plus URL. Plays immediately. No EPG support in VLC, but all channels stream directly from the playlist URL.

MyTV Online (Formuler)

My Services → Add Service → Type: Xtream. Enter Server (hostname only, no http://), Username, Password. Tap Save.

Kodi (IPTV Simple Client)

Add-ons → PVR IPTV Simple Client → Configure → Location: Remote Path → paste M3U_plus URL. Set EPG URL separately in the EPG settings tab.

Smart IPTV (Samsung/LG)

Open Smart IPTV app → note your TV's MAC address → visit siptv.eu/mylist/ on a browser → enter MAC address and M3U URL → click Send List.
