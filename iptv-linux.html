IPTV on Linux — Complete Guide

Linux is an excellent platform for IPTV streaming. With VLC Media Player, Kodi, and various mpv-based players, Linux supports all major IPTV playback methods — M3U playlists and Xtream Codes.

Every Mojo 4K subscription includes an M3U playlist URL that works with any M3U-compatible Linux player. VLC is the quickest to set up (open the URL in Media > Network Stream), while Kodi with the PVR IPTV Simple Client provides the best full-featured IPTV experience with EPG guide, channel categories, and VOD library.

For Raspberry Pi users, LibreELEC (a minimal Linux distribution running Kodi) is the most popular IPTV setup. A Raspberry Pi 4 with 4GB RAM handles HD IPTV streams easily, and 4K streams with hardware acceleration.

Set Up IPTV on Linux

1

Install VLC

sudo apt install vlc  or  flatpak install vlc

2

Get M3U URL

Subscribe to Mojo 4K — M3U URL by WhatsApp in 60 sec.

4

Upgrade to Kodi

For EPG guide: install Kodi + PVR IPTV Simple Client.

# Install VLC on Ubuntu/Debian
sudo apt update && sudo apt install vlc

# Play M3U stream directly (replace with your URL)

# Install Kodi on Ubuntu
sudo apt install kodi
