IPTV M3U Playlist URL 2026 — How to Get & Use It

An IPTV M3U playlist is a text file or URL containing a list of stream links for live TV channels. Every Mojo 4K subscription includes a personal M3U playlist URL that works in any M3U-compatible player, in addition to the Xtream Codes API credentials.

What Is an M3U Playlist?

An M3U file (Moving Picture Experts Group Audio Layer 3 URL) is a plain-text playlist format that lists media streams with their URLs. For IPTV, your M3U playlist URL points to a dynamically generated list of all 50,000+ channels in your subscription — including the stream URL, channel name, EPG ID, logo, and group tag for each channel.

How to Use Your Mojo 4K M3U URL

In TiviMate (Firestick / Android)

  1. Open TiviMate → Settings → Playlists → Add Playlist
  2. Select "M3U playlist" (not Xtream Codes)
  3. Paste your Mojo 4K M3U URL
  4. Name the playlist and save — channels load automatically

In Kodi (IPTV Simple Client)

  1. Install "PVR IPTV Simple Client" from Kodi Add-ons
  2. Configure → M3U Playlist URL → paste your Mojo 4K M3U link
  3. Set XMLTV URL to your EPG link (provided with subscription)
  4. Restart Kodi — channels appear under Live TV

In VLC Media Player (PC / Mac)

  1. Open VLC → Media → Open Network Stream
  2. Paste your M3U URL and click Play
  3. All channels load as a playlist in the sidebar

In GSE Smart IPTV (iOS / Android)

  1. Open GSE → Remote Playlists → Add M3U URL
  2. Paste your Mojo 4K M3U playlist URL and save
  3. Channels and EPG load within 30 seconds

Frequently Asked Questions

What is the difference between an M3U URL and Xtream Codes?+

An M3U URL is a direct link to a playlist file. Xtream Codes is an API that generates the playlist dynamically, supports catch-up TV, VOD browsing, and series organization. Both are included with every Mojo 4K subscription. TiviMate and IPTV Smarters work better with Xtream Codes; Kodi and VLC work better with M3U.

How do I get my Mojo 4K M3U URL?+

Your M3U playlist URL is included in the credentials sent to you via WhatsApp within 60 seconds of payment. It is formatted as http://server.mojo4ktv.com:PORT/get.php?username=USER&password=PASS&type=m3u_plus&output=ts

Does the M3U URL include EPG data?+

Yes. A separate XMLTV EPG URL is provided alongside your M3U URL. Paste it into TiviMate, Kodi IPTV Simple Client, or GSE Smart IPTV to load the full 7-day programme guide alongside your channels.

How many channels are in the Mojo 4K M3U playlist?+

The Mojo 4K M3U playlist contains 50,000+ live channel streams from 152 countries, organized by group (Sports, News, Entertainment, Kids, etc.) with HD and 4K variants listed separately for most major channels.
