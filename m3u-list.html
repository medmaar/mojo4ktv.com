M3U IPTV List — Frequently Asked Questions

What is an M3U list?
An M3U list (or M3U playlist) is a text file format that lists IPTV channels and their stream URLs. Each line in the file describes a channel name and stream address. Your Mojo 4K M3U URL points to a dynamically generated M3U file with all 50,000+ channels.
How do I use an M3U list?
Copy your M3U URL from your Mojo 4K credentials. Open your IPTV player (VLC: File > Open Network, TiviMate: Add Playlist > M3U URL, Kodi: PVR IPTV Client settings) and paste the URL. Channels load automatically.
Is M3U or Xtream Codes better for IPTV?
Xtream Codes (XC) is generally better: it provides channels, VOD and EPG in one connection, and apps like TiviMate have native XC support with better EPG integration. M3U is more universal — every player supports it. Mojo 4K provides both.
Can I use a free M3U list?
Free M3U lists (from GitHub or public sources) typically have unreliable streams, frequent dead links, no EPG and possible legal issues. A Mojo 4K subscription provides a maintained, stable M3U with 50,000+ working channels.
