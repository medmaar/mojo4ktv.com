How It Works

What is an IPTV M3U Playlist?

An M3U playlist (or M3U file) is a plain text file that lists IPTV channel stream URLs along with channel metadata. The format originated with MP3 playlists ("MP3 URL" = M3U) but is now the universal standard for IPTV channel lists. Each channel entry in the M3U file looks like this:

#EXTM3U
#EXTINF:-1 tvg-id="BBCOne" tvg-name="BBC One" tvg-logo="https://..." group-title="UK Channels",BBC One
http://server.mojo4ktv.com:8080/stream/bbcone

Your IPTV app reads this file and turns it into the channel list you browse. Mojo 4K's M3U playlist includes all 50,000+ channels with logos, categories, and EPG IDs for automatic programme guide loading.

Open Smart IPTV on your Samsung or LG TV, go to the web portal, and enter your M3U URL. All channels load with logos and categories on your Smart TV.

Add New User > Load Your Playlist / Xtream Codes > enter your M3U URL. Available on Android, iOS, Windows and Mac. Supports full EPG and VOD via Mojo 4K's M3U_plus format.

Kodi

Install PVR IPTV Simple Client add-on, enter your M3U URL in the General tab, and set your EPG URL. Kodi then shows all channels in the TV section with programme guide.

Open the app, add a Remote Playlist, and enter your M3U URL. Works on Android devices, Android TV boxes, and tablets with full channel list access.

IPTV M3U Playlist — FAQ

What is an IPTV M3U playlist?

An M3U playlist is a text file containing a list of IPTV stream URLs with channel metadata (name, logo, category, EPG ID). Your IPTV app reads this file to display and stream live channels. Mojo 4K provides an M3U_plus URL with all 50,000+ channels formatted with logos and categories.

Which is better: M3U playlist or Xtream Codes?

Xtream Codes is better for TiviMate and IPTV Smarters because it loads EPG automatically, provides access to 300,000+ VOD titles, and updates channels dynamically. M3U is better for VLC, Kodi, Smart IPTV and older players that do not support Xtream Codes. Mojo 4K provides both.

Do M3U playlists work on Smart TV?

Yes. Samsung Smart TV uses Smart IPTV app, LG Smart TV uses SS IPTV or Smart IPTV via webOS — both accept M3U URLs directly. Enter your Mojo 4K M3U URL in the app's URL field and all channels load on your Smart TV.

What is M3U_plus format?

M3U_plus is an extended version of the standard M3U format that includes extra metadata fields: tvg-id (EPG identifier), tvg-name, tvg-logo (channel logo URL), and group-title (category). Mojo 4K uses M3U_plus so apps like TiviMate and IPTV Smarters automatically display channel logos and organize channels by sport, country, and genre.
