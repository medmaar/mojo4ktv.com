What is an M3U8 IPTV Playlist?

M3U8 is the standard file format for IPTV playlists. The format evolved from the original M3U (MP3 URL) format to support UTF-8 character encoding — enabling channel names in any language including Arabic, Chinese, and special characters.

An M3U8 IPTV file starts with the #EXTM3U header, followed by #EXTINF entries for each channel containing the channel name, logo URL, and group category, then the stream URL on the next line.

Every Mojo 4K subscription includes an M3U8 URL — a hosted playlist that dynamically loads all 50,000+ channels with logos, EPG data, and group categories. This URL works in VLC, Kodi, TiviMate, IPTV Smarters Pro, and any M3U8-compatible player.

M3U8 Format Example:
#EXTM3U
#EXTINF:-1 tvg-name="ESPN" tvg-logo="http://..." group-title="USA Sports",ESPN
http://server.example.com:8080/live/user/pass/123.ts
#EXTINF:-1 tvg-name="BBC One" tvg-logo="http://..." group-title="UK",BBC One
http://server.example.com:8080/live/user/pass/456.ts
